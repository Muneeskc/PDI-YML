# Luxon TATA Yard Management System (YMS)

A complete Yard Management & PDI Inspection web application built for **Luxon TATA** (PDI Supervisor & Stock In-Charge).

## Features
- **Vehicle Inward & Barcode Scanning**: Scan VIN/Chassis using live camera or uploaded image. Auto-detects duplicate entries.
- **PDI Inspection & Multi-Photo Support**: Capture all-round vehicle photos, checksheets, VIN, Form 22/28, and battery voltages.
- **PDF Report Generation & Telegram Bot Dispatch**: Automatically generates structured PDI PDF reports and dispatches them directly via Telegram Bot (`@YmsPro_bot`) to management groups.
- **Google Sheets Backend Sync**: Real-time logging of Inwards, Stock status, PDI inspections, and Outward dispatches.

## Deployment on GitHub Pages
1. Upload `index.html` to your GitHub repository.
2. Go to **Settings > Pages**.
3. Set the source branch to `main` (or `master`) and `/ (root)`.
4. Your live app URL will be generated instantly!
